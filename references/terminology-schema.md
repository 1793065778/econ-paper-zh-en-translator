# Terminology, Acronym, And Variable Schema

Treat terminology management as a core translation mechanism. Build the table before full translation, update it before and after each chapter, and audit it before completion.

## Required Fields

```markdown
| Chinese source term | English rendering | Acronym | Variable symbol | First full form | Later short form | Forbidden rendering | Requires confirmation | First occurrence | Last updated chapter |
|---|---|---|---|---|---|---|---|---|---|
```

## Rules

- Use one English rendering for one Chinese source term unless the source context truly requires distinction.
- Record forbidden renderings when a tempting translation would be inaccurate.
- Spell out acronyms at first use, then use the short form later.
- Preserve variable symbols exactly.
- Do not translate variable symbols as prose unless explaining them in review notes.
- Mark uncertain terms as requiring confirmation rather than silently choosing.
- Update the table after every chapter because later context may clarify earlier choices.

## Review Notes

For each paragraph with important terminology, record:

- paragraph ID
- key terms used
- acronym behavior
- variable symbols preserved
- any term requiring user confirmation
