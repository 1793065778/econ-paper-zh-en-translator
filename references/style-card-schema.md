# Dynamic Style Card Schema

Build style cards from user-provided or AI-found target-journal examples. Do not use static journal tricks. Extract only transferable expression patterns.

## Corpus Rules

- Use user-provided examples first.
- If examples are absent or insufficient, find 8-10 suitable papers.
- Prioritize similarity in field, method, data object, and target journal.
- If the corpus is weak, state the limitation before applying style.

## Allowed Extraction

Extract:

- sentence patterns
- paragraph progression patterns
- section-specific expression habits
- terminology preferences
- causal language strength
- uncertainty language
- policy implication boundaries
- useful syntactic patterns
- transfer limits for the current manuscript

Do not extract:

- substantive claims
- findings
- datasets
- mechanisms
- conclusions
- contribution framing
- wording that would be copied into the translation

## Card Format

```markdown
### Style Card: <short name>

- Source example:
- Target section:
- Match type: field / method / data object / journal / general style
- Transferable expression pattern:
- Paragraph progression pattern:
- Causal language strength:
- Uncertainty language:
- Policy implication boundary:
- Useful syntax:
- Prohibited content transfer:
- Transfer limit for this manuscript:
```

## Application Rule

Use style cards to shape English expression after the source meaning is secured. Do not let a style card override the Chinese manuscript's facts, structure, claim strength, or evidence chain.
